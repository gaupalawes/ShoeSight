# Hours Taken till now: 5.6 hrs

Finally finished the schematic of the project after tons of issues. I used XIAO ESP32-C3 as a base microcontroller as it is small and works for my project fine. I use MPU-6050 as a accelerometer to detect any movements to solve any issue arise when the foot is in the midair while swinging. I used VL53LOC for the time of flight obstacle detector using lasers.
